# Brasa & Massa

Landing page de hamburgueria e pizzaria. Artesanal. Quente. Irresistível.

## Como abrir

Abra o arquivo `index.html` no navegador. Não precisa instalar nada.

## O que tem na página

- Hero com o burger principal
- Destaques "Fresh & Hot"
- Cardápio com filtro por categoria (Burgers, Pizzas, Combos, Bebidas)
- Produto em destaque (Trufada Premium)
- Depoimentos de clientes
- Chamada final para pedido e rodapé

## Tecnologias

- HTML, CSS e JavaScript puro, num arquivo só
- Fontes Anton e Inter (Google Fonts)
- Fotos geradas por IA, otimizadas em WebP e embutidas no HTML
